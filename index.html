인식하는 메시지 형식 
토픽이 접점 이름으로 끝날 때
  plc/Y10  →  1 / 0, on / off, true / false
한 토픽에 여러 접점
  plc/D100 →  0 / 1 / 2
한 토픽에 여러 접점
  plc/io   →  {"X0":1,"X2":0,"Y10":1,"D100":2}
  plc/io   →  X0=1,Y10=1,D100=2
